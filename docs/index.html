🔑 Cấp key VideoToolsPro

—

Lấy tại Supabase Dashboard → Project Settings → API → Secret keys. Key này có toàn quyền ghi/xoá dữ liệu — chỉ dán ở đây, không gửi cho ai.

Secret key chỉ nằm trong trình duyệt điện thoại này, không gửi đi đâu ngoài Supabase. Mất điện thoại thì vào Supabase Dashboard → Settings → API → Secret keys, bấm huỷ/tạo lại key đó là xong.

Thêm vào màn hình chính: Safari bấm Chia sẻ → Thêm vào MH chính, Chrome bấm ⋮ → Thêm vào màn hình chính.
