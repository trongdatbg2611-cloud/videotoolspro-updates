Cấp key Muse AI Studio

—

Để trống: key tự khoá vào Gmail + máy đầu tiên khách nhập. Điền sẵn: khách phải nhập đúng Gmail này.

Mật khẩu là chuỗi trong hàm muse_admin_ok của file muse_supabase_setup.sql. Lộ mật khẩu: sửa chuỗi đó trong Supabase SQL Editor rồi Run lại — các key đã cấp không ảnh hưởng.

Thêm vào màn hình chính: Safari bấm Chia sẻ → Thêm vào MH chính, Chrome bấm ⋮ → Thêm vào màn hình chính.
Thu hồi key: app của khách bị khoá trong vòng ~2 phút. Khách đổi máy: Tra cứu → Gỡ khoá máy, khách nhập lại key trên máy mới.
